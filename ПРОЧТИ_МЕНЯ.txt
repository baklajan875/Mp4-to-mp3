MP4 → MP3 + РЕЧЬ → ТЕКСТ + ДОКУМЕНТЫ   (Windows 10/11 x64)
==========================================================

ЗАПУСК
------
Двойной клик по MP4ToMP3.exe. Устанавливать ничего не нужно.
Java и FFmpeg уже лежат внутри этой папки; для распознавания речи
один раз скачается языковая модель (~44 МБ, нужен интернет).
Документы (Word и PDF) работают сразу и без интернета.

ВАЖНО: не переносите один MP4ToMP3.exe отдельно от папки —
работает вся папка целиком (exe + app + runtime + ffmpeg).
Ярлык: правый клик по MP4ToMP3.exe → «Отправить» → «Рабочий стол».

ЕСЛИ WINDOWS ПИШЕТ «ЗАЩИТИЛА ВАШ КОМПЬЮТЕР»
--------------------------------------------
Так бывает с любой программой без платной цифровой подписи.
Что делать:
 1. Нажмите «Подробнее» в синем окне.
 2. Затем «Выполнить в любом случае».
 3. Или заранее: правый клик по exe → «Свойства» → внизу галочка
    «Разблокировать» → «ОК».
Подписи нет по одной причине: сертификат стоит денег и оформляется
на организацию. Сам файл при этом ничего не меняет в системе, не
ставит службы и не лезет в интернет, кроме страницы загрузки модели.

ЕСЛИ ЗАПУСТИЛИ ДВА РАЗА
-----------------------
Второй экземпляр честно скажет «Программа уже запущена»: иначе два
бота на одном токене мешают друг другу, а сервер для телефона не
может занять тот же порт.

ЛЁГКАЯ СБОРКА (без FFmpeg)
--------------------------
Если в архиве нет папки ffmpeg — это версия «лайт» (~55 МБ вместо 94).
FFmpeg скачается сам при первом запуске («Настроить FFmpeg…»), нужен
интернет один раз. Полная сборка интернет не требует вообще.

1) ИЗВЛЕЧЬ ЗВУК ИЗ ВИДЕО
------------------------
«Добавить файлы…» (или перетащите MP4 в окно) → выберите папку →
качество (192 kbps универсально) → «Извлечь MP3».

2) РАСПОЗНАТЬ РЕЧЬ В ТЕКСТ
--------------------------
Меню «Инструменты» → «Речь → текст…» (или кнопка в главном окне).
Добавьте MP3/MP4/WAV — кнопкой «Добавить файлы…», кнопкой
«Добавить папку…» (заберёт все записи с подпапками) или перетащите.
Выберите язык → «Распознать».

ЧТО МОЖНО ВКЛЮЧИТЬ (галочки в окне распознавания)
-------------------------------------------------
• PDF .pdf — готовый документ A4: заголовок, дата, нумерация страниц.
  Текст в нём выделяется и ищется, шрифт встроен — откроется одинаково везде.
• Word .docx — то же в виде документа Word.
• Субтитры .srt / .vtt — таймкоды для плееров и веба.
• Таймкоды .json — каждое слово со своим временем (для монтажа).
• Или просто выберите готовый набор в списке «Что сохранять».
• Улучшать звук — шумоподавление и выравнивание громкости.
  Помогает на записях с телефона, с улицы, с тихим голосом.
• Пунктуация и абзацы — точки, заглавные буквы и абзацы
  расставляются по паузам в речи (офлайн).
• Вшить субтитры в копию видео — рядом появится «фильм (субтитры).mp4»
  с отдельной дорожкой субтитров, без перекодирования видео.
• Пропускать уже готовые файлы — можно закрыть программу и продолжить
  позже: список и отметки [готово] сохраняются.

Кнопки «Копировать текст» (в буфер обмена) и «Открыть .txt» — рядом с результатом.

3) ДОКУМЕНТЫ: WORD И PDF
------------------------
Кнопка «Документы и PDF…» в главном окне (или меню «Инструменты»,
или Ctrl+D). Откроется окно с четырьмя вкладками.

• DOCX → PDF. Вкладка «DOCX → PDF»: выберите файл Word — рядом появится PDF.
  Заголовки, курсив, размеры шрифта, таблицы и разрывы переносятся,
  страницы нумеруются. Кириллица встроена в файл: PDF откроется одинаково
  на любом компьютере. Можно выбрать сразу несколько документов.

• PDF-редактор. Вкладка «PDF-редактор»: список страниц с миниатюрами.
  Поворот страницы — Ctrl+[ и Ctrl+], поворот всех сразу — «Все влево/вправо»
  (пригодится для сканов «боком»). Порядок — «Выше» и «Ниже» (Alt+↑/↓).
  «Удалить» (или кнопка Delete) убирает страницу; последнюю удалить нельзя.
  «Вставить фото…» добавит картинку отдельной страницей.
  Исходный файл не меняется: правки сохраняются через «Сохранить как…» (Ctrl+S).

• Фото → PDF. Вкладка «Фото → PDF»: добавьте фотографии (или перетащите их),
  поверните нужные, расставьте порядок, лишние удалите. Формат страницы:
  A4 книжный, A4 альбомный, Letter или «по размеру фото»; поля в миллиметрах
  и качество JPEG. Получится один аккуратный PDF вместо россыпи снимков.

• Свойства DOCX. Вкладка «Свойства DOCX»: название, тема, автор, ключевые слова,
  категория, примечания, «последний изменил», ревизия, язык, организация,
  руководитель, даты создания и изменения. Эти поля видит проводник Windows,
  поиск и Word. Кнопки «Создан = сейчас» и «Изменён = сейчас» подставят время.
  Текст и оформление документа при этом не меняются вообще.
  Если документ открыт в Word — закройте его перед сохранением.

• В обоих списках есть ползунок «Масштаб»: миниатюры можно сделать крупнее
  или мельче — удобно и на ноутбуке, и на большом экране.

• Справка: «Справка» → «Возможности программы» (F1) — коротко о всех функциях.

ГОРЯЧИЕ КЛАВИШИ
---------------
Ctrl+O — добавить файлы        Ctrl+Shift+O — добавить папку
Ctrl+Enter — начать            Esc — остановить
Ctrl+C — копировать текст      Ctrl+E — окно «Речь → текст» из главного окна
Ctrl+F — поиск по тексту       F3 — следующее совпадение
Alt+←/→ или Ctrl+↑/↓ — по репликам   Ctrl+T — тёмная тема
Ctrl+D — окно «Документы и PDF»      F1 — справка с поиском
Ctrl+M — окно «Телефон и сеть»
Ctrl+[ / Ctrl+] — повернуть фото или страницу PDF влево / вправо
Alt+↑ / Alt+↓ — переместить выше / ниже   Delete — удалить выбранное
Ctrl+S — сохранить (PDF-редактор, свойства DOCX)

ГДЕ ЛЕЖИТ МОДЕЛЬ РАСПОЗНАВАНИЯ
------------------------------
Новые модели скачиваются сюда:
  Windows:  %LOCALAPPDATA%\MP4ToMP3\models
            (обычно C:\Users\<вы>\AppData\Local\MP4ToMP3\models)
  Linux:    ~/.mp4mp3/models

Уже скачанную модель программа найдёт и в других местах — качать заново не нужно:
  • папка models рядом с MP4ToMP3.exe;
  • модель, распакованная прямо рядом с MP4ToMP3.exe;
  • %LOCALAPPDATA%\MP4ToMP3\models и %APPDATA%\MP4ToMP3\models;
  • ~/.mp4mp3/models и ~/MP4ToMP3/models;
  • ~/Downloads и ~/Загрузки.

Точный путь виден в окне распознавания в строке «Модель найдена: …».
Наведите на неё мышь — покажется список всех мест поиска.

ПЕРВЫЙ ЗАПУСК И ПРОВЕРКА (версия 1.9)
--------------------------------------
• Мастер первого запуска. При первом запуске — три шага: куда сохранять
  результаты, FFmpeg (найдётся или скачается), модель распознавания.
  На каждом шаге галочкой видно, что уже готово. Вернуть мастер:
  «Справка» → «Мастер настройки…».

• «Проверить распознавание» — третья кнопка на последнем шаге мастера.
  Программа сама произносит короткую фразу и показывает, что услышала.
  Десять секунд — и понятно, что всё работает, ещё до первой лекции.

• «Проверить всё» (Справка → «Проверить всё…» или F9). Пятнадцать проверок
  списком: FFmpeg и кодек MP3, модель, PDF и шрифты, папка результатов,
  место на диске, журнал, настройки, телефон и бот. У каждой — приговор
  (ок / внимание / не работает) и подсказка, что делать. Кнопка
  «Сохранить отчёт…» кладёт рядом файл диагностика-дата.txt — его можно
  просто приложить к письму. Токены и PIN в отчёт не попадают.

• Обновление в один клик. «Справка» → «Проверить обновления…»: программа
  скачает архив, сверит контрольную сумму, распакует и перезапустится.
  Раз в неделю проверяет сама (отключается в том же меню). Если новая
  версия не понравилась — «Вернуться на прежнюю версию…».

• Сводка для телефона и мониторинга. Адрес/health — короткий ответ, жив ли
  и что делает; /metrics — цифры для мониторинга, только после PIN.

ЧТО ЕЩЁ УМЕЕТ ПРОГРАММА (версия 1.8)
------------------------------------
• Не тратит время на паузы. Галочка «Пропускать тишину»: программа за секунды
  измеряет, где речь, а где молчание, и паузы не распознаёт. Субтитры при этом
  остаются с правильными таймкодами.

• Словарь замен. Кнопка «Словарь замен…»: пишете «ентерпрайз = Enterprises» —
  и так будет во всём тексте, субтитрах, Word и PDF. Файл dictionary.txt лежит
  рядом с программой, его можно править хоть в блокноте.

• Поиск по тексту. Ctrl+F, Enter — следующее совпадение. Рядом появится время:
  «в записи это 12:34» — удобно, когда нужно вернуться к этому месту.

• Готовые субтитры → Word и PDF. Перетащите в окно .srt, .vtt, .txt или .json —
  документы появятся сразу, распознавать заново не нужно.

• Длинные записи режутся на части примерно по 30 минут: «фильм (часть 1).pdf».
  В одном файле на двести страниц слишком трудно что-то найти.

• Ходить по репликам. Кнопки ‹ › рядом с поиском (или Alt+←/→): по очереди
  выделяются фразы, и видно время каждой — «реплика 2 из 13 • 0:06–0:11».
  Клик по любому месту текста тоже покажет, когда это было сказано.

• Тёмная тема — Вид → Тёмная тема (Ctrl+T). Переключается на лету и запоминается.

• Документы без интернета. Word → PDF, правка PDF (поворот, порядок, вставка
  и удаление страниц), PDF из фотографий, свойства DOCX. Всё считается на
  вашем компьютере: файлы никуда не отправляются.

• Все свойства Word правятся. Вкладка «Свойства DOCX»: название, автор, тема,
  ключевые слова, ревизия, время редактирования и число сохранений — всё можно
  поменять, остальной документ останется байт в байт прежним.

• Справка с поиском. F1 открывает отдельное окно с 12 разделами и строкой
  поиска: пишете «пауза», «потоки», «телефон» — сразу видно нужный раздел.

• Распознавание на нескольких ядрах. В окне распознавания есть строка «Потоки».
  На двух ядрах работа идёт примерно в 1,8 раза быстрее, на восьми — в 3–5 раз.

• С телефона — как с пульта. «Инструменты» → «Телефон и сеть…»: включаете сервер,
  наводите камеру телефона на QR-код в окне, вводите PIN — и телефон в той же
  Wi-Fi сети может отправлять файлы, запускать обработку и забирать результаты.
  Когда задача готова, сверху выезжает уведомление.

• Папка-наблюдай. «Инструменты» → «Папка-наблюдай…»: выбрали папку — и всё, что в неё
  попадает, само идёт в очередь. Удобно, когда файлы приходят по сети или из облака.

• История задач. «Инструменты» → «История задач…»: последние 200 задач с кнопкой
  «Повторить» — не нужно заново искать файлы.

• Готово — и вы узнаете. Если окно свёрнуто, в правом нижнем углу появляется
  уведомление. Всё важное пишется в log/mp4mp3.log рядом с программой.

• Профили задач в окне распознавания: «Интервью», «Лекция», «Кино» — один выбор
  вместо пяти галочек.

• Телеграм-бот (по желанию). Пересылаете боту видео — файл скачивается на ваш
  компьютер, дальше кнопки «MP3», «Распознать речь» и другие. Доступ только у вас
  (код привязки), по умолчанию бот выключен.

ЧТО НОВОГО В 1.9.7
------------------
• Помнит уже обработанное — по содержимому файла, а не по имени.
  Тот же фильм под другим именем, из другой папки или с флешки не будет
  обрабатываться второй раз: готовый MP3 просто скопируется, а в журнале
  появится строка «MP3 взят из памяти». Качество входит в отпечаток, поэтому
  тот же фильм в 320 kbps после 192 kbps будет сделан заново. Если готовый
  файл удалили — программа сделает его снова.

• Одинаковые файлы отсеиваются при добавлении: из трёх файлов, где два —
  один и тот же фильм, в список попадут два, а в строке состояния появится
  «Пропущено копий: 1 (тот же файл, что «фильм.mp4»)».

• «Инструменты» → «Память MP3 и обработки…»: сколько помню, «Почистить
  удалённые» и «Забыть всё». Сами файлы при этом не удаляются.

• Очередь продолжается после выключения компьютера. При следующем запуске
  программа спрашивает: «Продолжить с того места, где остановились?» —
  [Продолжить] [Не сейчас] [Больше не спрашивать]. Работает и в окне
  «MP4 → MP3», и в окне «Речь → текст». Файлы, которых больше нет на диске,
  пропускаются, а «готовый» с удалённым результатом ставится обратно в работу.
  Как вести себя при запуске — в settings.ini:
    resumeQueue=ask    — спрашивать (по умолчанию)
    resumeQueue=auto   — продолжать молча
    resumeQueue=never  — не спрашивать

ПОЛЕЗНАЯ ЦЕПОЧКА
----------------
Извлекли MP3 из видео — в окне «Готово» нажмите «Распознать эти файлы…»,
и они сразу окажутся в окне распознавания. Не нужно искать их заново.

• Работает офлайн: звук никуда не отправляется, распознавание идёт на вашем ПК.
• Пока идёт обработка, компьютер не уходит в сон; по завершении —
  звуковой сигнал и окно само выходит на передний план.
• Настройки хранятся в файле settings.ini рядом с MP4ToMP3.exe, если папка
  доступна для записи, — тогда всю папку можно носить на флешке.
• Языки: русский, английский, немецкий, французский, испанский.
• Точная русская модель (1.8 ГБ) даёт меньше ошибок, если есть место на диске.
• Всё управляется с клавиатуры (Tab, Enter, F1, F9, F10 — меню), у каждой кнопки
  есть имя для экранного диктора.
• Речь без пауз и сильный шум ухудшают качество — это ограничение любой
  офлайн-модели такого размера.

СКОРОСТЬ
--------
Извлечение звука — обычно 15–40× быстрее реального времени.
Распознавание — примерно 10–15× быстрее реального времени:
часовая запись обрабатывается за 4–7 минут. Если в окне распознавания
выбрать несколько потоков, время сокращается ещё в 1,5–4 раза — зависит
от числа ядер.

ЕСЛИ ЧТО-ТО НЕ ТАК
------------------
• Начните с F9 («Справка» → «Проверить всё…»): программа сама скажет, что сломано —
  нет FFmpeg, нет модели, нет прав на папку, мало места. Там же «Сохранить отчёт…»:
  файл диагностика-дата.txt можно приложить к письму (токены и PIN в него не попадают).
• «Сообщить о проблеме…» в меню «Справка» собирает версию, систему и журнал в один файл.
• Журнал всегда рядом: log/mp4mp3.log; старый уходит в mp4mp3.old.log, файл не растёт.
• SmartScreen «Windows защитила ваш компьютер» → «Подробнее» → «Выполнить в любом случае»
  (программа не подписана сертификатом — это платно).
• «Модель ещё не скачана» → нажмите «Скачать модель» (один раз).
• «Не удалось скачать модель… handshake_failure» (антивирус, прокси, блокировка сайта) →
  скачайте zip-архив модели в браузере с https://alphacephei.com/vosk/models
  и нажмите в окне распознавания «Указать вручную…» → «Выбрать .zip-архив…».
  Распаковывать не нужно. То же меню: «Инструменты» → «Установить модель распознавания из файла…».
• «Речь не распознана» → выбран не тот язык модели или в записи нет речи.
• «В этом файле нет аудиодорожки» → в видео нет звука.
• DRM-файлы (покупки из магазинов) не обрабатываются — это защита.
• Извлекайте звук и распознавайте только те записи, на которые у вас есть права,
  и предупреждайте людей, если записываете разговор.
